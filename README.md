# ПФ-Агент — кликабельный демо-прототип

Статический сайт (HTML/CSS/JS, без сборки и зависимостей). Все данные вымышлены, кроме рыночных показателей Банка России.

## Локальный запуск
    python3 -m http.server 8000   # открыть http://localhost:8000

## Бесплатная публикация
- **GitHub Pages:** залить содержимое папки в корень ветки `main` → Settings → Pages → Branch: `main` / root.
- **Vercel:** Add New Project → импортировать репозиторий (Framework: Other, без build-команды) или `npx vercel --prod` из этой папки.
- **Netlify Drop:** перетащить папку на app.netlify.com/drop.

## Структура
- `index.html` — каркас, `styles.css` — стили (цвета Сбера и ДомКлика: переменные `--sber`, `--dc` в начале файла)
- `data.js` — все тестовые данные, `app.js` — страницы и интерактив
